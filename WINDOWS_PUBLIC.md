# Cockpit Solaire — Windows 3.0.0

[Télécharger le paquet Windows public](https://github.com/magerericsev-design/terrelfe/releases/tag/v3.0.0-windows-public)

Décompressez entièrement `CockpitSolaire-Windows-public-3.0.0.zip`, puis lancez **CockpitSolaire.exe**. Conservez le dossier `CockpitData` à côté de l’exécutable. Le runtime Python est inclus ; Microsoft WebView2 doit être disponible sur Windows.

Le fichier EXE correspond à l’installation actuelle d’Eric et reste inchangé. Le paquet public inclut un classeur entièrement fictif, une base neuve et une configuration vide, avec une bannière de démonstration. Les données réelles, identifiants Linky/APsystems, clés API, historiques et sauvegardes personnelles sont exclus.

Dans cette copie publique seulement, le moteur ignore la configuration vide pour permettre l’ouverture sans compte API. Pour utiliser votre installation, suivez `LISEZ-MOI.txt`, fournissez vos propres données et configurez vos propres accès. Ne partagez jamais `config.local.json`, votre classeur personnel ni votre base de données.

Contrôles : EXE identique à l’original (SHA-256), intégrité ZIP, démarrage du lanceur jusqu’au menu prêt, rendu du tableau de bord de démonstration avec le runtime livré, états API non configurés. L’ouverture complète du tableau de bord à l’intérieur de WebView2 n’a pas été revalidée dans cette publication. Les intégrations réelles nécessitent une configuration propre à chaque utilisateur.
